## 🚀 Start
1. Install the tools in [SETUP.md](SETUP.md).
2. Keep your work in your own branch (`git switch -c solutions/<your-name>`) or in a fork.
3. Open [SYLLABUS.md](SYLLABUS.md) and start with the first lab.

## 🧭 How the labs work
- 🧩 **Challenge:** `starter/` has TODOs and failing tests; make them green. `solution/` is there on purpose: you decide when to look.
- 🔭 **Exploration:** a working `demo/`; predict, run, compare.
- 💭 **Concept:** read, then answer the self-assessment.
- 🏗️ **Project:** at the end of each block; build it from `BRIEF.md` and compare with `reference/`, or review the reference with `REVIEW.md`.

## 💬 Feedback
Finished a lab? Open a **Lab feedback** issue: what was clear, what was hard, what you would change. Feedback improves this lab and the next ones.
